# PROJECT INFORMATION

## Project Name

**Moriarty**

## Project Title

**ML- and LLM-Assisted Adaptive Security Patch Verification Framework**

## Core Tagline

**"Don't trust the patch. Challenge it."**

## One-Line Pitch

Moriarty is an intelligent security verification framework that independently challenges security patches using ML-guided risk analysis, LLM-assisted reasoning, adaptive testing, and evidence-backed verification to determine whether a vulnerability has actually been fixed.

## Core Problem

Developers frequently fix vulnerabilities and assume the application is secure because:

- The vulnerable code was modified.
- A static analysis tool reports an improvement.
- A patch generator produces a candidate fix.
- A test case passes.
- An ML model assigns a lower risk score.

However, none of these alone proves that the vulnerability has been eliminated.

A patch can:

- Fix one vulnerability while leaving another attack path.
- Introduce incomplete sanitization.
- Change SQL query behavior.
- Break legitimate functionality.
- Pass predefined tests while failing on unfamiliar inputs.
- Appear safe to the same system that generated it.

Moriarty addresses this trust problem by independently analyzing and challenging candidate security patches.
